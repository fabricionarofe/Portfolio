## 🚀 Como Executar Localmente

1. Clone o repositório.
2. Navegue até a pasta `automacao-de-mensagem`.
3. Instale as dependências (via `requirements.txt` ou equivalente).
4. Execute o arquivo principal (`main.py` ou `index.js`).
